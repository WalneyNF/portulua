Manual de Referência do PortuLua

Uma linguagem de programação criada por Walney Moreira Klein (walneyk@hotmail.com).

Introdução

O PortuLua é uma linguagem de programação didática baseada no Portugol (VisuAlg), mas com superpoderes modernos. Ela foi projetada para rodar diretamente no navegador, permitindo que você aprenda lógica de programação, crie algoritmos complexos e até faça integrações com a internet.

Todo programa no PortuLua deve ser salvo com a extensão de arquivo .wmk.

Estrutura Básica

Todo programa deve começar com a palavra algoritmo seguida de um nome, e terminar com fimalgoritmo. Os comandos ficam dentro do bloco inicio e fimalgoritmo.

algoritmo "MeuPrimeiroPrograma"
inicio
   // Seus comandos vão aqui
   escreval("Olá, Mundo!")
fimalgoritmo

Variáveis e Tipos

As variáveis devem ser declaradas antes do bloco inicio, usando a palavra var. O PortuLua possui quatro tipos básicos:

TipoDescriçãoExemplo
inteiroNúmeros inteirosidade: inteiro
realNúmeros decimaisaltura: real
caractereTextos e letrasnome: caractere
logicoVerdadeiro ou Falsoaprovado: logico

Para ler um valor do usuário, use leia(). Para exibir na tela, use escreva() (sem pular linha) ou escreval() (pulando linha).

var
   nome: caractere
   idade: inteiro
inicio
   escreval("Qual seu nome?")
   leia(nome)
   escreval("Bem-vindo, ", nome)

Operadores

  • Aritméticos: + (soma), - (subtração), * (multiplicação), / (divisão).
  • Relacionais: = (igual), <> (diferente), >, <, >=, <=.
  • Lógicos: e, ou, nao.

A atribuição de valores a variáveis é feita com o operador <-.

idade <- 18
media <- (nota1 + nota2) / 2
se idade >= 18 e aprovado = verdadeiro entao ...

Estruturas de Controle

Condicionais (Se / Escolha)

se idade >= 18 entao
   escreval("Maior de idade")
senao
   escreval("Menor de idade")
fimse

escolha opcao
   caso 1
      escreval("Opção 1")
   outrocaso
      escreval("Outra opção")
fimescolha

Laços de Repetição (Loops)

O PortuLua tem os três laços clássicos:

// Para (For)
para i de 1 ate 10 faca
   escreval(i)
fimpara

// Enquanto (While)
enquanto i > 0 faca
   i <- i - 1
fimenquanto

// Repita (Do-While)
repita
   escreval("Digite 0 para sair")
   leia(x)
ate x = 0

Funções Personalizadas

Você pode criar blocos de código reutilizáveis que recebem parâmetros e retornam um valor. Elas devem ser declaradas após o fimalgoritmo do programa principal.

funcao calcularDobro(x: inteiro): inteiro
inicio
   retorne x * 2
fimfuncao

Vetores (Arrays)

Vetores permitem armazenar múltiplos valores em uma única variável. A indexação no PortuLua começa no número que você definir (ex: 1).

var
   notas: vetor[1..4] de real
inicio
   notas[1] <- 10.0
   notas[2] <- 8.5
   escreval(notas[1])

Integração com APIs (A Mágica!)

O PortuLua possui comandos exclusivos para conversar com a internet e ler JSON. Esses comandos tornam a linguagem capaz de criar automações reais.

requisicao(url)

Faz uma requisição HTTP GET para a URL informada e baixa os dados (JSON).

pega_json("chave")

Retorna o valor de uma chave do último JSON baixado pela função requisicao().

⚠️ Aviso sobre CORS: Para que as APIs funcionem sem bloqueio de segurança, o arquivo da IDE deve estar rodando em um servidor local (como VS Code Live Server) ou na web (GitHub Pages), não direto no disco (file:///).

Exemplo: Consulta de CEP

algoritmo "BuscaCEP"
var
   url, logradouro: caractere
inicio
   url <- "https://viacep.com.br/ws/01001000/json/"
   requisicao(url)
   logradouro <- pega_json("logradouro")
   escreval("Rua: ", logradouro)
fimalgoritmo
